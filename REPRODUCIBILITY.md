# Reproducibility checklist

The paper (`docs/main.pdf`) reports the `profile: full` run of
`config.xai.yaml`: 57 stocks, 16 models, 22 catalogued XAI methods.
`profile: reviewer` is a small, fast configuration of the same pipeline.

## Data and problem definition
- [x] Public data set (FNSPID); the files used are documented in
      `modal/s1_data.py`. The raw data are not redistributed; the panel is
      rebuilt by `modal/s2_build.py`.
- [x] Features use only information available at the close of day t; targets
      are the next-day log return and its direction.
- [x] News is aligned to trading sessions (news after 16:00 New York time is
      assigned to the next session); sentiment is aggregated per stock and
      session.
- [x] Universe: 57 US large-cap stocks, chosen from 81 sector-diverse
      candidates by data availability only (at least 150 news days and a
      complete 2015-2023 price history). See
      `results/metrics/universe_selection.json` and
      `results/metrics/fnspid_price_coverage.json`.
- [x] Daily returns with |r| > 0.5 are masked as data errors. The rule is
      fixed in `config.xai.yaml` and applied when the panel is built.
- [x] Planted features (`modal/s2_build.py::assemble`): `gt_noise`,
      `gt_signal` (rho = 0.15), `gt_signal_weak` (rho = 0.05), `gt_signal_nl`
      (sign-coded, rho = 0.15), `gt_redundant_copy`, `gt_redundant_partial`
      (rho = 0.8). Seed 42. The construction and the realized correlations
      are logged in `results/feature_manifest.json`.

## Evaluation protocol
- [x] Model zoo: expanding-window walk-forward with four test years
      (2020, 2021, 2022, 2023). Training rows for test year Y are dated more
      than 10 calendar days before 1 January of Y
      (`modal/s3_experiments.py`).
- [x] Scalers are fitted on training rows only.
- [x] No hyperparameter search and no validation split for model selection.
      Hyperparameters are constants in the code; the sequence models and the
      GNN are trained for a fixed number of epochs (12; 15 for the
      Transformer). The scikit-learn MLP and the EBM use
      their library-default internal early-stopping split of the training
      rows.
- [x] Baselines: persistence and historical mean (returns), majority class
      and always-up (direction).
- [x] `Symbol` is one-hot encoded for the tabular models of the zoo.
- [x] Recovery scoring (`modal/s5*.py`, `modal/s7_faithfulness.py`): models
      are trained on all rows before 2023 and scored on the rows of 2023. No
      embargo is applied at this stage.
- [x] Stability checks (`modal/s7b_faithfulness_robustness.py`): scored years
      2021, 2022, 2023, with the model trained on all other years (so the
      2021 and 2022 repetitions train on later years and are not out-of-time
      evaluations); leave-10-stocks-out with 200 draws.

## Inference
- [x] Stock-resampled percentile intervals: 5,000 resamples of whole stocks.
- [x] The model is fitted once and each importance vector is computed once
      before resampling. Variation between training seeds and the sampling of
      the explainers are not included in the intervals.
- [x] Dependence between stocks is reported (mean pairwise return correlation
      0.381; about 2.55 independent units under equal correlation) and is not
      removed by the resampling.
- [ ] Repeated training runs (seed variance) for the recovery scores.
- [ ] A resampling scheme that accounts for dependence between stocks and
      over time.

## XAI methods
- [x] 22 methods catalogued; 13 scored on their own feature-importance
      output; 9 not scored on feature recovery. The list and the per-model
      counts are generated into `paper/tables/tab_method_recovery.tex`.
- [x] Reference-library implementations: SHAP (TreeSHAP, KernelSHAP), LIME,
      scikit-learn permutation importance, captum (Integrated Gradients, LRP,
      guided backpropagation, deconvnet, Grad-CAM), `interpret` (EBM),
      PyTorch Geometric (GNNExplainer).
- [x] Simplified implementations in this repository: Anchors, counterfactual
      search, the contrastive explanation method, RISE (feature masking),
      Grad-CAM++, Score-CAM, the decision-tree surrogate, rank-aggregated
      TreeSHAP, the sparse autoencoder, and the single-component ablation
      sweep.
- [x] Null checks: TCAV against 100 random concept vectors
      (`modal/s5g_tcav_null.py`); sparse-autoencoder and ablation counts
      against 20 feature shuffles (`modal/s5h_mechanistic_null.py`).
- [ ] Recovery scoring of the Grad-CAM variants on their own output (needs a
      planted signal that is localized in time).
- [ ] Controlled models with known dependencies (a direct test of
      faithfulness), and planted interactions between features.

## Manuscript and artifact
- [x] Every result in the paper is generated by `make_tables.py` from
      `results/` into `paper/numbers.tex` and `paper/tables/`.
      `paper/NUMBERS_AUDIT.md` lists the source of each number.
- [x] `python make_tables.py` regenerates the tables and numbers from the
      stored results without Modal (needs pandas, numpy, pyarrow).
- [x] Seed 42 throughout; metrics stored as JSON/CSV, figures as PNG.
- [x] `requirements.txt` pins the versions of the Modal image;
      `make reproduce` runs the whole pipeline. `run_all.sh` is an older
      entry point and is not maintained.
- [x] The notebooks are executed records of the first version of the
      project; they need `results/panel.parquet`, which is rebuilt by the
      pipeline and is not stored in the repository.
